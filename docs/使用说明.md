# 使用说明

实际任务“将玉米放到盘子上”的完整逐指令现场流程见
[2026-09-15_01_实际采集逐指令操作说明.md](2026-09-15_01_实际采集逐指令操作说明.md)。

## 环境边界

在 `code/` 内使用 uv 和 Python 3.10 执行采集、预检、HDF5 校验和测试：

```bash
UV_CACHE_DIR=/tmp/uv-cache uv sync --extra dev --extra realsense
```

Pika ROS 只在 Conda 的 `pika` 环境中启动。不要在 uv 环境中执行 ROS launch，也不要修改 `/home/cv/pika_ros`。

## 现场顺序

1. 使用 `configs/piper_x_d405_d435.example.yaml` 和 `configs/pika_sense_piper_x.example.yaml` 创建本机配置副本。
2. 核对 `can0` 已由现场人员启用，并确认 `robot.firmware_version` 与 Piper-X 实机固件一致。
3. 运行 `piper-x-collect preflight --config <采集 YAML>`；只有返回 `pass` 时才继续。
4. 先启动 Pika Sense 传感器，再在 `pika` Conda 环境运行 `teleop_single_piper_x.launch.py`。快速开合 Sense 夹爪两次以开启遥操。
5. 通过 `piper-x-collect teleop-session` 采集；第一次空格结束采集并写盘，实体遥操停止后第二次空格关闭 ROS，随后按空格保留或按 `d` 删除本条轨迹。

## 控制边界

`preflight`、`read-piper-x-state` 和 `collect` 只读取 pyAgxArm 的 Piper-X CAN 反馈。原装 AGX 夹爪只接受 `width` 模式的反馈值，并以米写入数据集。它们不会使能或移动机械臂，也不会向夹爪发送命令。

`robot.initial_pose.enabled: true` 是唯一的项目内主动控制路径，只会在遥操 ROS 启动前执行。它使用低速 `move_j` 或 `move_p`，到位后断开 CAN。若超时或出现控制错误，程序请求 pyAgxArm 电子急停；确认机械臂安全、按现场流程复位后才能继续。
