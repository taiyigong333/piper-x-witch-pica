# 使用说明

实际任务“将玉米放到盘子上”的完整逐指令现场流程见
[2026-09-15_01_实际采集逐指令操作说明.md](2026-09-15_01_实际采集逐指令操作说明.md)。

## 环境边界

配置按职责分目录：`configs/cameras/` 保存相机参数，`configs/teleop/` 保存遥操参数，`configs/tasks/` 保存任务参数。采集 YAML 的 `session.camera_parameters_file` 指向本次使用的 JSON；同一个 `batch_N` 首次采集后会锁定摘要，后续不一致会直接拒绝。

相机 JSON 的每个 `cameras[].options` 可配置 RealSense 参数，例如 `exposure`、`white_balance`、`enable_auto_exposure` 和 `enable_auto_white_balance`。启动时程序会写入这些 option；所有传感器支持的 option 都会读取其当前值、只读状态、范围（最小值、最大值、步长、默认值）和描述，并将请求值与设备实际值保存到 batch 的 `camera_parameters.json`。

在 `code/` 内使用 uv 和 Python 3.10 执行采集、预检、HDF5 校验和测试：

```bash
UV_CACHE_DIR=/tmp/uv-cache uv sync --extra dev --extra realsense
```

Pika ROS 只在 Conda 的 `pika` 环境中启动。不要在 uv 环境中执行 ROS launch，也不要修改 `/home/cv/pika_ros`。

## 现场顺序

1. 使用 `configs/tasks/`、`configs/teleop/` 和 `configs/cameras/` 下的示例创建本机配置副本。
2. 核对 `can0` 已由现场人员启用，并确认 `robot.firmware_version` 与 Piper-X 实机固件一致。
3. 运行 `piper-x-collect preflight --config <采集 YAML>`；只有返回 `pass` 时才继续。
4. 先启动 Pika Sense 传感器，再在 `pika` Conda 环境运行 `teleop_single_piper_x.launch.py`。快速开合 Sense 夹爪两次以开启遥操。
5. 通过 `piper-x-collect teleop-session` 采集。预检通过后一次确认“基站已校准且可安全移动”即可；相机会在机械臂前往起始位姿时开始预热，预热帧不保存。Sense 确认遥操后才开始写入轨迹；随后按空格结束采集、实体遥操停止后再按空格关闭 ROS，最后按空格保留或按 `d` 删除本条轨迹。

## 常用指令

```bash
uv run piper-x-collect preflight --config configs/tasks/grab_rotating_red_square_into_blue_plate.yaml
uv run piper-x-collect teleop-session --config configs/tasks/grab_rotating_red_square_into_blue_plate.yaml --teleop-config configs/teleop/pika_sense_piper_x.example.yaml --reverse-recording
uv run piper-x-collect trajectory-viewer --root /home/cv/gcj/data_collect/data
uv run piper-x-collect validate <batch_N/采集时间/forward/normal_trajectory.hdf5> --config <采集 YAML>
```

数据目录为 `data/batch_N/<采集时间>/forward` 和 `reverse`，批次根目录同时保存 `camera_parameters.json`。

## 控制边界

`preflight`、`read-piper-x-state` 和 `collect` 只读取 pyAgxArm 的 Piper-X CAN 反馈。原装 AGX 夹爪只接受 `width` 模式的反馈值，并以米写入数据集。它们不会使能或移动机械臂，也不会向夹爪发送命令。

`robot.initial_pose.enabled: true` 是唯一的项目内主动控制路径，只会在遥操 ROS 启动前执行。它使用低速 `move_j` 或 `move_p`，到位后断开 CAN。若超时或出现控制错误，程序请求 pyAgxArm 电子急停；确认机械臂安全、按现场流程复位后才能继续。
