# 相机参数调整说明

本文说明 `configs/camera/*.json` 中 RealSense RGB 参数的调整方法。当前任务使用固定参数，避免连续采集过程中自动曝光反复变化。

## 参数含义

| 参数 | 单位/范围 | 作用 |
| --- | --- | --- |
| `width`、`height` | 像素 | 分辨率，必须与任务 YAML 的相机配置一致 |
| `fps` | 帧/秒 | 采样频率；提高它通常会限制可用曝光上限 |
| `exposure` | RealSense option 数值 | 曝光时间。增大画面变亮，但运动拖影和过曝风险增加 |
| `gain` | RealSense option 数值 | 传感器增益。增大画面变亮，但噪声增加；固定模式下默认不额外设置 |
| `white_balance` | Kelvin 近似值 | 色温。通常先保持两台相机一致，再按现场光源调整 |
| `enable_auto_exposure` | `0`/`1` | 是否启用硬件自动曝光 |
| `enable_auto_white_balance` | `0`/`1` | 是否启用硬件自动白平衡 |

## 当前任务参数

任务 `grab_rotating_red_square_into_blue_plate.yaml` 当前使用：

```text
configs/camera/piper_x_balanced_brighter.parameters.json
```

当前起始值：

| 相机 | 曝光 | 目的 |
| --- | ---: | --- |
| D435I (`camera_front`) | `120` | 比 `80` 增亮，同时低于此前过曝的 `166` |
| D405 (`camera_wrist_right`) | `12000` | 比 `8000` 增亮，低于造成拖影的 `33000` |

## 调整顺序

1. 先固定 `fps=30`、分辨率和白平衡，只调整 `exposure`。
2. D435I 画面过曝时，每次降低 10 到 20；画面偏暗时，每次增加 10 到 20。
3. D405 出现运动模糊时优先降低曝光；画面偏暗但运动已经清晰时，再小幅增加曝光。
4. 不要同时打开自动曝光和写入固定曝光。自动模式会覆盖手动曝光，适合预览，不适合要求跨帧一致的固定采集。
5. 修改后用已保存参数预览工具检查实际画面：

```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python -m tool.realsense_camera.saved_preview \
  --name piper_x_balanced_brighter.parameters.json
```

按 `q` 或 `ESC` 退出。确认画面后再执行正式采集；修改参数文件后，新的 `batch_N` 批次应重新开始，因为同一批次会锁定相机参数摘要。

预览工具支持完全图形化修改并另存为新文件。点击参数行左侧或右侧的 `- / +` 调整，点击数值区域弹出精确输入窗口；点击自动曝光/自动白平衡行切换开关，点击分辨率文本可修改宽高并重启对应相机流。点击“另存为新参数文件”后，在弹窗填写新 JSON 文件名和 `purpose`。源文件名会被拒绝，原参数文件不会被修改。

## 自动调参对照

需要重新让硬件 AE/AWB 收敛时，使用 `rgb_auto_tune.py`。它会显示收敛后的 RGB 画面，按 `s` 才保存，按 `q` 放弃。收敛结果用于观察和建立新固定参数，不建议未经人工确认直接替换正式采集文件。
